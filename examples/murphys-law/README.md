# 示例：墨菲定律（技术参考，不是模板）

这支 150 秒的片子是按本 skill 的流程只拿到主题"墨菲定律"做出来的（`treatment.md` 是它的创意方案）。它的形式是**侦探调查**：一面案件墙，五件倒霉事是证物，宇宙是被告，最后翻出 1949 年的原始档案。这一切都只属于墨菲定律，**别的主题不要用案件墙、盖章、证物卡**。

可以学的是技术：

- `src/World.tsx` + `src/board.ts`：一个贯穿全片的空间。卡片、图钉、红线（从卡片边缘到边缘）、印章都画在世界坐标里，用 `TL` 读各个场景的事件来同步；`live()` 让卡片的静态缩略图和场景里的动态版本互补淡入淡出；`boardOpacity()` 按"份额"算墙的可见度，pan 的时候墙不会变暗。
- storyboard 里每个场景的 `cam` + `"in": {"type": "pan", "bow": 0.5}`：镜头在墙上从一张卡飞到另一张。
- `CardSpace.tsx`：场景的动态画面跟着卡片的倾斜角一起转，严丝合缝。
- `Act1.tsx` 的 `Montage`：按 downbeat 硬切的蒙太奇，每一段一个拟音。
- `Act2.tsx` 的 `CityZoom`：一个 canvas 画几千个点，镜头按拍子分级拉远。
- `Act3.tsx` 的 `Launch`：全片唯一的全彩画面：天空渐变、视差滚动的轨道、尾焰、计数器、刹车时的水雾。
- storyboard 里的拟音：`stamp` `thud` `knock` `scratch` `tap` `select` `error` `thruster`……按材料选声音，重要时刻叠层。

用法：只在想读代码学技巧时看。不要把这些文件复制进新主题的项目。
