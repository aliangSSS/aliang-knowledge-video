# 默认 BGM

所有主题默认用 `assets/bgm/default.mp3`（用户的曲子《claude算法小曲》）。`python tools/prepare_bgm.py` 不带参数就用它。只有用户明确给了别的音乐才换。不要自己生成配乐。

## 结构（实测）

150.1 秒 · 114.84 BPM（一拍 0.522s，一小节 2.087s）· F 大调。三段几乎一样的 50 秒循环，每段都是"安静 → drop → 满"：

| 段 | 时间 | 音乐 | 叙事用途 |
|---|---|---|---|
| 第一幕 | 0–10.3 | 开头就有鼓，能量中等 | 钩子：开场就要动、要快 |
| | 10.3–16.5 | 抽空的 breakdown，16.3 左右最空 | 把问题立起来；画面收拢 |
| | **16.54** | **drop 1** | **标题** |
| | 16.5–50 | 满 → 中 | 第一幕正文（2–3 场） |
| 第二幕 | 50–62.4 | 安静的过渡 | 转折、换角度、"可是……" |
| | 62.4–66.3 | 蓄力，66.3–66.7 曲子自带一次真空 | 加速、收紧 |
| | **66.58** | **drop 2（全曲最强）** | **核心揭晓** |
| | 66.6–100 | 满 → 中 | 第二幕正文 |
| 第三幕 | 100–112.5 | 安静 | 反转的铺垫（历史、档案、"其实……"） |
| | 112.5–116.4，116.4–116.7 真空 | 蓄力 | 倒数、收紧 |
| | **116.64** | **drop 3** | **反转 / 全片唯一全彩** |
| | 116.6–145 | 满 → 中 | 反转展开、落到观众自己 |
| 尾声 | **145.83** | 最后一个重音，之后 4 秒淡出 | **片尾** |

`beats.json` 的 `hits` 就是 title 16.54 / reveal 66.58 / twist 116.64 / end 145.83。分镜里用 `"anchor": "title"` 等把场景钉上去。

downbeat（小节第一拍）：1.95, 4.04, 6.12, 8.21, 10.30, 12.39, 14.48, 16.54, 18.63 …（每 2.087s 一个）。场景切换会自动吸到这些点上。

## 这首曲子对画面的要求

- 鼓很密，音效要短而有棱角才听得见：用真实拟音（stamp、thud、knock、click、tap）比合成的柔和音色更清楚。
- drop 前曲子自己会抽空。不要再加 `duck`，画面跟着收（变暗、收成一点、停住），然后在 drop 上硬切。
- 三个 drop 的结构完全一样，所以三处高潮的"样子"必须不同（比如 盖章 / 公式砸下 / 全彩爆发），不然会觉得在重复。
- 每支片子都是同一首曲子，所以**开场、标题、揭晓、反转的画面一定要按主题重新设计**，否则所有片子会看起来一模一样。

## 时长

默认 150 秒（整首）。内容不够或太多时：`python tools/prepare_bgm.py --target 120`（剪掉中间一段，保留开头和结尾）。不建议短于 100 秒：三个 drop 会挤在一起。
