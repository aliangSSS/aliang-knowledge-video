# 创意设计：每个主题都要重新设计

**最重要的一条**：示例片《墨菲定律》之所以是"倒霉事蒙太奇 → 案件墙 → 盖章立案 → 证物一件件翻案 → 1949 年档案"，是因为它讲的是墨菲定律：大家觉得是运气在作对，所以把它拍成一桩需要翻案的冤案；这条定律出自一次工程事故，所以反转是那次火箭滑车实验。换一个主题，这些一个都不该出现。

不变的只有品牌：暗底、光、细衬线中英字幕、无旁白、画面卡拍、事件配音效（见 style.md）。开场、叙事形式、画面世界、转场、动效性格、声音、标题怎么出、反转是什么，全部从这个主题自己的内容里长出来。

## 写 `notes/treatment.md`（动手前必须写完）

1. **核心洞见**：一句话。观众看前怎么想 → 看后怎么想。
2. **这个主题自己的世界**：列 15 个以上只属于它的东西：物件、场景、人物、历史事件、数字、日常体验、反直觉的现象。画面只从这张表里取。
3. **统一的视觉空间**：整部片发生在哪里？一面案件墙、一张地图、一条时间轴、一台机器的内部、一个培养皿、一张棋盘、一座城市的夜景、一封信……选一个能装下全部章节的空间，镜头在里面移动（用 World + cam，见 components.md）。空间也可以是"一个物件从头到尾在变形"。
4. **叙事形式**（选一个，写出为什么）：

| 形式 | 适合 | 例子 |
|---|---|---|
| 游戏 / 谜题 | 能让观众边看边猜的 | 博弈论（囚徒困境）、概率（三门问题）、密码学（猜密码） |
| 侦探调查 | 有"常见误解 / 冤案"的 | 墨菲定律（宇宙无罪）、安慰剂效应、赌徒谬误 |
| 尺度旅行（一镜到底推拉） | 讲大小、数量级、增长的 | 复利、宇宙尺度、指数增长、细胞 |
| 时间线 / 编年 | 讲一个东西怎么演变来的 | 文字、货币、计算机、疫苗 |
| 拆解 / 剖面 | 讲"它是怎么工作的" | 发动机、二维码、GPS、心脏 |
| 思想实验 | 讲物理 / 哲学概念 | 薛定谔的猫、忒修斯之船、电车难题 |
| 一天 / 一生 | 讲日常里藏着的规律 | 生物钟、多巴胺、注意力 |
| 倒计时 / 危机 | 讲"再不……就……" | 抗生素耐药、气候临界点 |
| 对照实验 | 两种情况对比出真相 | 棉花糖实验、双盲试验 |
| 收藏册 / 图鉴 | 一组并列的同类现象 | 认知偏差、悖论、错觉 |

5. **开场钩子**：第一帧就在动。前 3 秒是什么画面、什么声音；前 16 秒（第一个 drop 之前）怎么把问题立起来。常用：慢动作里的熟悉一刻 / 快切蒙太奇 / 一个反直觉的数字 / 先给结局再倒叙 / 一个观众会本能答错的问题 / 一个不可能的画面。
6. **三个音乐高潮放什么**（默认 BGM 的三个 drop，见 bgm.md）：标题怎么出？中段揭晓是什么？反转是什么？每个都写清楚画面 + 声音。
7. **转场语法**：选 1–2 种主转场 + 1 种特殊转场，和空间一致。在一面墙上就用 pan；尺度旅行就用 zoom；一台机器就用 wipe（像拉开面板）；数据 / 错误就用 glitch。三个 drop 上一律硬切（cut / flash）。
8. **动效性格**（和主题的物理性质一致）：机械（卡扣、齿轮、回弹）/ 重力（下落、弹跳）/ 扩散（慢慢晕开）/ 生长（指数、弹簧）/ 旋转（匀速、正弦）/ 数码（瞬切、扫描、乱码）/ 流体。用 `spring` `fall` `Kinetic` 的不同模式，不要所有东西都 easeInOutCubic 淡入。
9. **声音调色板**：这个世界由什么材料组成，就用什么声音。纸 / 木 / 金属 / 玻璃 / 电子 / 自然 / 机械。按视觉事件列出：落下用什么、点亮用什么、错误用什么、转场用什么（`samples.py` 里的真实拟音 + 合成音效）。
10. **唯一的全彩画面**：在哪里、画的是什么、为什么它配得上全片唯一。
11. **防套用自查**（每条都要回答"是"才能开工）：
    - 把主题换成另一个，这套方案还成立吗？成立就是太通用了，重来。
    - 有没有用到示例片或你之前做过的片子的开场 / 标题 / 揭晓 / 反转 / 结尾？有就换。
    - 每一章的画面，是不是只有这个主题才会这样画？
    - 有没有哪一场只是"黑底 + 一句话 + 一个小图"？有就重画。

## 画面的标准（比"能看懂"高）

- **一屏一个主体，主体要大**：占画面宽度 35% 以上。小图标居中、四周大片空黑是不合格的。
- **有层次**：前景 / 中景 / 背景，至少两层（比如墙 + 卡片 + 卡片上的动画；城市 + 你；天空 + 山 + 轨道 + 滑车）。
- **永远在动**：镜头慢推（drift，默认就有），或者元素在呼吸、漂移、闪烁。没有一帧是完全静止的。
- **错开出场**：一组东西依次出场（stagger），不要同时淡入。
- **动作有前因后果**：东西掉下来要有重力，盖章要先压扁再回弹，线要从一头画到另一头，数字要滚动。
- **字的出场方式也要设计**：`Kinetic` 有 9 种模式，按主题选（数据用 scramble、重的用 slam、轻的用 blur）。
- **画的东西具体**：不要用抽象圆点和方块代表一切。排队就画收银台和人，吐司就画吐司和桌子，滑车就画滑车和尾焰。

## 示例：同一套工具，四个主题四种片子

| | 墨菲定律（examples/murphys-law） | 二维码（假设） | 复利（假设） | 生物钟（假设） |
|---|---|---|---|---|
| 空间 | 一面案件墙 | 一个二维码的内部（每个格子是一块地砖） | 一张不断拉远的棋盘 → 城市 → 地球 | 一间卧室，窗外从夜到昼 |
| 形式 | 侦探调查 | 拆解：一次扫码的 0.1 秒 | 尺度旅行 | 一天 |
| 开场 | 五件倒霉事的快切蒙太奇 | 手机"嘀"一声扫中，镜头钻进码里 | 棋盘第一格一粒米 | 凌晨 3 点，闹钟没响人先醒了 |
| 标题 | 盖章立案 | 黑白格子一格格翻转，拼出标题 | 米粒堆成标题 | 窗外的光一格格亮起，拼出标题 |
| 揭晓 | 真凶公式 P = 1−(1−p)ⁿ | 三个角上的大方块只管定位，其余是数据和纠错 | 第 64 格的米 = 全世界产量的上千倍 | 身体里有一个约 24 小时的钟，光每天给它对时 |
| 反转（全彩） | 1949 火箭滑车点火 | 缺了一角照样能扫：被补回来的部分全彩亮起 | 一生的储蓄曲线突然起飞 | 飞过 8 个时区：全彩世界地图上，身体里的钟各走各的 |
| 转场 | 墙上 pan + 硬切 | glitch + 格子翻转 | 连续 zoom | wipe（一道光扫过房间） |
| 动效 | 机械、带重量 | 数码、逐格点亮 | 指数生长 | 慢、周期、呼吸 |
| 声音 | 纸、木、章、钉子 | 扫码嘀、按键、电子噪声 | 硬币、米粒 | 闹钟、心跳、鸟鸣 |
