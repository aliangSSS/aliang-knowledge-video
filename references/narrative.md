# 叙事与文案

## 结构

没有固定模板。先按 design.md 选叙事形式（游戏 / 侦探 / 尺度旅行 / 时间线 / 拆解 / 思想实验……），再把它放进默认 BGM 的三幕骨架（bgm.md）：

| 音乐 | 叙事位置 | 要做到 |
|---|---|---|
| 0–16.5 开场 + breakdown | 钩子 + 立问题 | 第一帧就在动；16 秒内让观众想知道答案 |
| **16.54 drop 1** | 标题 | 标题的出场方式要属于这个主题 |
| 16.5–50 | 第一幕正文 | 2–3 场；每场一个具体的可视化 |
| 50–66.5 安静 → 蓄力 | 转折："可是……" | 换角度、加速、收紧 |
| **66.58 drop 2（最强）** | 核心揭晓 | 全片最重要的一句话 / 一个公式 / 一个数字 |
| 66.6–100 | 第二幕正文 | 揭晓的后果、放大、验证 |
| 100–116.5 安静 → 蓄力 | 反转的铺垫 | 历史 / 原始现场 / "其实……" |
| **116.64 drop 3** | 反转（全片唯一全彩） | 让观众重新理解前面所有的东西 |
| 116.6–145.8 | 落到观众自己 | 一个可以带走的做法 |
| **145.83 最后一个重音** | 片尾 | 回扣开场，标题落下，随尾音淡出 |

这是骨架，不是格式：标题可以是盖章、是米粒堆出来、是圆转出笔画；揭晓可以是公式、是一张图、是一个数字；反转可以是一段历史、一个反例、一次镜头拉远。每一处都按主题设计。

每章常用的结构：一个问题 → 一个具体的可视化 → 一个锚点（年份 · 人物 · 地点，角落小字）→ 一个数字或公式（双语标签）→ 一句结论字幕。不必每章都齐，但每章至少要有那个可视化。

## 文案

- 无旁白，全部信息靠字幕 + 画面。一条字幕讲一件事。
- 第二人称、短句：中文每条 ≤ 22 字（标点不算）。
- 英文是意译不是直译：斜体，简洁，有文学感。
- 数据、年份、人名必须准确，每条都在 `notes/sources.md` 里有来源；只有二手来源或说法有争议的，要么换掉，要么在字幕里用"相传"并在 sources 里写明争议。
- 不堆术语：术语第一次出现前，观众先在画面里体验过它。
- 例子用中文语境里的日常：地铁、外卖、排队、热搜、天气、古诗。
- 屏幕上的字（场景里的标签、标题）和字幕不要说同一句话。
- 字幕密度：约 8–10 条/分钟（150 秒 ≈ 20–25 条）。build 会报告。

## `notes/publish.md`

标题（≤ 20 字，有悬念，不剧透核心洞见）+ 80–150 字简介 + 5 个标签。
