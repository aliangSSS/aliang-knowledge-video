# 节奏与声音

"看着舒服"的关键：节奏分三层，各管各的。`build.py` 已经实现了这些规则，这里讲为什么，以及写分镜时怎么选。

## A. 叙事层（字幕）跟阅读速度走，不卡拍

- 淡入 / 淡出各 0.2 秒（全局 `Subtitles`）。
- 停留 = max(3.5 秒, 中文字数 × 0.22 + 1.0)，build 自动算，场景有富余时最多拉长 30%。
- 同场景两条间隔 0.8–1.0 秒；跨场景 1.5–3 秒。
- 字幕只需要大致落在乐句边界附近，**不要对齐拍点**：字幕也卡拍会显得机械。

## B. 事件层（画面动作）严格卡拍

- 场景切换落在 downbeat 上（build 自动吸附），转场在那一拍"落地"。
- 每个场景一个主事件（盖章、落地、揭晓、点亮），对齐到 drop / 强拍：anchor、`"@reveal"`、`"snap": "downbeat"`。画面可以比声音早不到 1 帧，不能晚。
- 重复动作（打字、计数、一步一步的过程、滚动）锁 1 拍或半拍：`"repeat": {"every": 1}`。
- 揭晓前加速：`"roll": [1, 1, 0.5, 0.5, 0.25, 0.25]`，最后一下落在强拍上。

## C. 呼吸层（转场与留白）

- 转场是"呼吸"：它的时长、方向、声音都在讲两场之间的关系。同一个空间里的下一件事 → pan；更深一层 → zoom；换一个世界 → black / blur；一个画面推开另一个 → push / wipe；出错 / 数据 → glitch。转场方式从 design.md 的"转场语法"里选，全片统一。
- drop 前 0.3–1 秒收紧：画面变暗、收成一点、停住，或者倒数。默认 BGM 在 drop 前自己会抽空，所以不用加 duck；在 drop 上**硬切**（`cut` / `flash`）+ 重击音效 + `shake`。
- 每场结尾留一点空（`tail`），不要让字幕顶着转场。

## 结构对齐

默认 BGM 的三个 drop（16.54 / 66.58 / 116.64）和片尾重音（145.83）是全片的四根柱子（bgm.md）。标题、核心揭晓、反转、片尾分别钉在上面（`"anchor": "title" | "reveal" | "twist" | "end"`）。其余场景在柱子之间按内容分配时间。

## 声音设计

卡点感大部分来自"每个视觉事件都有一个专属音效"：BGM 负责情绪，音效负责标点。

- **按材料选声音**（storyboard.md 的音效表）：这个画面里的东西是什么做的，就用什么声音。纸 → `scratch` `tap`；木 → `knock` `wood`；金属 → `metal`；玻璃 → `clink`；按钮 / 屏幕 → `click` `select` `error`；重的东西落下 → `thud`；印章 → `stamp`；发动机 → `thruster`。真实拟音比合成音更有质感，在默认 BGM 很密的鼓里也更听得见。
- **合成音用在"非物理"的事件上**：点亮（`bell` `chime`，按调性）、光线（`glide` `whoosh`）、转场（`swish` 自动配）、真空（`suck`）、分量（`sub`）。
- **重要时刻叠层**：`["stamp", {"type": "sub"}, {"type": "hit", "gain": -4}]` = 一声有分量的重击；BGM 会自动让 3 dB（`autoDuck`）。
- **声像**：`pan` 跟画面位置走（左边的东西 -0.5），移动的东西用 `[a, b]` 扫过去。
- 响度已按类型对 BGM 校准；同一时刻最多两个不同的声音；音效和画面来自同一个事件，保证同一帧。
- 我（模型）听不到声音：交付时要说明混音需要用户自己听，告诉他改 `gain` / `meta.sfxGain`。
