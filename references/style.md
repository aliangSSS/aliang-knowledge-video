# 视觉系统

分两层：**品牌**（每部片子都一样，观众认得出是这个系列）和**这一部的世界**（每个主题重新设计，见 design.md）。

## 品牌（固定）

数值写在 `src/lib/theme.ts`（`C` `FONT` `SIZE` `MAIN_Y`）。

- **暗**：整体平均亮度低（约 4%），光才"亮"得起来。底色默认近黑偏蓝，中心 `#050910`、四角 `#020202`。
- **色彩语义**（每屏最多两种强调色）：

| 颜色 | 常量 | 含义 |
|---|---|---|
| 暖白 `#EDEDE9` | `C.text` | 正文、主句、线稿 |
| 金 `#F6D392` / 光晕 `#E3AA5E` | `C.gold` / `C.goldGlow` | 重点、"是"、被点亮的、答案 |
| 冷青 `#5E8C9A` | `C.cyan` | 可预测的、"否"、结构性的 |
| 绯红 `#A53A5B` / 遮罩 `#621E30` | `C.crimson` / `C.crimsonMask` | 错误、噪声、被排除的、警告 |

  **全片只允许一处真正的全彩画面**，留给反转。
- **只有被强调的东西发光**（`glowText()`、`GlowDot`、`DrawPath` 的头），其余是细线和低透明度。
- **字体**：中文 Noto Serif SC Light/Regular（`FONT.zh`，300/400），英文 Lora Italic（`FONT.en`）。字体随 npm 装在本地，渲染前预加载片中所有的字。
- **双语字幕**：全局 `<Subtitles>`，底部居中，中文 44px 暖白 90%，约 85% 高度；英文斜体 26px、55% 不透明度紧贴其下。**75% 高度（y > 810）以下不放画面元素**，那是字幕区。
- **主句**：72–90px，字距 0.25–0.35em，约 40% 高度（`MAIN_Y`）。宽字距居中文本要加同样大小的 `paddingLeft`。
- **元信息**（年份 · 人物 · 地点、"第 3 问"）：`<Meta>`，角落 28px，低对比，字距拉开；它是 HUD，镜头动它不动。
- **数字 / 公式**：衬线斜体 + 下面一行小号中英标签（`FormulaCard`、`Label`）。

## 这一部的世界（每个主题重新设计）

- **底色可以变**：用 storyboard 的 `meta.bg` 调背景（暖一点的纸 / 木世界、更冷的太空、没有星星的实验室），或 `meta.bg: false` 让 `World` 自己画。保持"暗"。
- **空间**：一面墙、一张地图、一台机器内部、一座城市……画在 `World.tsx` 里，镜头（`cam`）在里面移动。
- **画什么**：只画这个主题自己的东西（design.md 第 2 条那张表）。线稿为主，细线、圆角、低透明度；需要实体感时用深色填充 + 一圈亮边。
- **动效性格**：和主题的物理性质一致（design.md 第 8 条）。工具：`lib/anim.ts` 的 `ramp` `easeInOutCubic` `easeOutQuint` `spring`（弹簧，可调回弹）`fall`（重力 + 回弹）`pulse` `settle`；文字用 `Kinetic` 的 9 种模式。
- **镜头**：默认每个场景慢慢推近 2%（drift）；用 `cam` / `camTo` 做平移、推拉；`shake` 给重击。镜头基本不晃、不乱转。

## 画面标准（每一帧）

1. 一屏一个主体，主体占画面宽度 35% 以上。不要小图标居中、四周大片空黑。
2. 至少两层（背景空间 + 主体，或主体 + 前景细节）。
3. 永远在动：drift、呼吸、漂移、闪烁、粒子。没有完全静止的帧。
4. 一组东西错开出场（stagger），出场有方向和力度。
5. 画具体的东西（收银台、吐司、滑车、尾焰），不要用抽象圆点和方块代表一切。
6. 文字不出画、不叠字、不压字幕；每屏强调色 ≤ 2；中文是细宋体不是黑体。

## 性能

- 大面积 CSS `filter: blur()` 和大量 `drop-shadow` 很慢；光晕用径向渐变。
- 成百上千个点用一个 canvas 画（`useLayoutEffect` 里按帧画，参考 `TvSnow`）。
- 渲染默认 3 个浏览器标签并行（`render.py`）；内存不够就 `--concurrency 2`。
